## 🧠 Concepts You'll Learn

### 1. What is Generative UI?

**Traditional App**: Developer designs UI → ships it → every user sees the same thing.

**Generative UI**: AI decides WHICH component to show → generates it in real-time → each user sees different UI based on their needs.

```
Traditional:  User asks "teach recursion" → AI returns TEXT explanation
Generative:   User asks "teach recursion" → AI returns an INTERACTIVE QUIZ COMPONENT
```

**Why this is the future**: By 2030, apps won't have static pages. The interface itself will be generated by AI based on context.

---

### 2. Tool Calling — AI Triggers Your Code

**The Key Insight**: LLMs can't just generate text — they can "call tools" (functions you define). This is how AI decides to show a quiz instead of text.

```typescript
// You define tools the AI can use:
const tools = {
  generateQuiz: {
    description: "Generate an interactive quiz for the student",
    parameters: z.object({
      question: z.string(),
      options: z.array(z.string()),
      correctAnswer: z.number(),
    }),
    // When AI calls this tool, render a React component:
    generate: async function* ({ question, options, correctAnswer }) {
      yield <QuizWidget question={question} options={options} answer={correctAnswer} />;
    },
  },
};

// The AI CHOOSES when to use this tool based on context.
// Ask "what is recursion?" → AI might respond with text.
// Ask "quiz me on recursion" → AI calls generateQuiz tool.
```

**This is how ChatGPT, Perplexity, and Claude work internally** — they call tools to show search results, code blocks, images, etc.

### 3. streamUI() — The Magic Function

```typescript
import { streamUI } from 'ai/rsc';

const result = await streamUI({
  model: google('gemini-2.5-flash'),
  messages,
  text: ({ content }) => <div>{content}</div>,  // Default: render as text
  tools: {
    quiz: {
      description: "Show an interactive quiz",
      parameters: quizSchema,
      generate: async function* (params) {
        yield <QuizWidget {...params} />;         // Tool: render quiz component
      },
    },
    flashcard: {
      description: "Show a flashcard for memorization",
      parameters: flashcardSchema,
      generate: async function* (params) {
        yield <Flashcard {...params} />;          // Tool: render flashcard
      },
    },
  },
});
```

**What happens**:
1. AI reads the user's message
2. AI decides: "Should I respond with text or use a tool?"
3. If tool → AI generates the parameters (question, options, etc.)
4. Your code receives those parameters → renders the matching React component
5. Component streams to the browser in real-time

---

### 4. Component Registry Pattern

Instead of hardcoding which component to render, we create a "registry" — a map from type names to components:

```typescript
// Component Registry — maps AI decisions to React components
const componentRegistry = {
  quiz: QuizWidget,
  flashcard: Flashcard,
  'code-editor': CodeEditor,
  diagram: Diagram,
  'progress-chart': ProgressChart,
} as const;

// AI returns: { type: "quiz", data: { ... } }
// We look up: componentRegistry["quiz"] → QuizWidget
// We render: <QuizWidget {...data} />
```

**Industry Pattern**: This is the same pattern used in design systems (Storybook), CMS platforms (headless content), and plugin architectures.

---

### 5. Zod — Validating AI Output

AI output is unpredictable. It might return malformed data. Zod catches this:

```typescript
import { z } from 'zod';

// Define what valid quiz data looks like:
const quizSchema = z.object({
  question: z.string().min(10),                    // Must be a string, 10+ chars
  options: z.array(z.string()).min(2).max(6),      // 2-6 string options
  correctAnswer: z.number().min(0).max(5),         // Index of correct answer
  explanation: z.string().optional(),               // Optional explanation
});

// If AI returns garbage, Zod throws an error instead of crashing your app.
```

## ❌ Common Mistakes & Fixes

| Mistake | Fix |
|---------|-----|
| AI never calls tools, only returns text | Make tool descriptions clearer and more specific |
| Zod validation fails | Check AI's output format matches your schema |
| Components flash/re-render | Use `key` props correctly on dynamic components |
| Tool called with wrong params | Add `.describe()` to Zod fields so AI knows what each field is |
